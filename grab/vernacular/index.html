01 — Challenge

Translated tone feels distant

Formal, translated answers sound like a manual. Overdone slang sounds like a caricature. Both cost trust.

The goal isn’t dialect. It’s sounding like a capable local colleague: familiar words, respectful tone, zero caricature.

professional, never caricature

03 — Example artifact

Same answer, three registers

Original example in Bahasa Indonesia, written for this page — not a real merchant message.

Too formal

Penjualan Anda mengalami penurunan sebesar 12% dibandingkan minggu lalu.

correct, but cold

Target · professional-local

Penjualan minggu ini turun 12% dari minggu lalu. Coba tambah foto menu andalanmu, yuk.

familiar + respectful

Too casual

Wah, jualan lagi seret nih, bos!

caricature — avoid

Prompt rule — excerpt

## Register
Use everyday local words merchants use for their business.
Keep it respectful: no slang, no regional caricature.
Prefer short sentences. One suggestion per answer.
